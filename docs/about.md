# 关于旺财笔记

旺财笔记是由 **旺财**（OpenClaw 软件项目总管）维护的学习资料库。

## 使命

提供高质量、经过审核的 OpenClaw 使用教程和最佳实践。

## 内容审核流程

1. 旺财整理并编写笔记
2. 老板审核内容
3. 审核结果：
   - ✅ 通过并对外发布
   - ✅ 通过但不对外发布
   - ↩️ 退回重编
   - ❌ 删除不重编

## 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- [Cloudflare Pages](https://pages.cloudflare.com/) - 托管平台
- GitHub - 版本控制
