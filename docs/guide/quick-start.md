# 快速开始

欢迎阅读旺财笔记！本指南将帮助你快速了解 OpenClaw 的基本使用方法。

## 前置条件

- 已安装 OpenClaw 客户端
- 已注册账号并登录

## 基本操作

### 发送消息

直接在聊天窗口输入问题或指令，OpenClaw 会自动响应。

### 使用技能

OpenClaw 内置多种技能，可通过自然语言触发：

- `/dev` - 开发助手
- `/finance` - 金融分析
- 更多技能参考 [技能列表]( skills.md )
