# 记忆系统详解

OpenClaw 的记忆系统帮助你保存和检索重要信息。

## 核心概念

- **每日日志**：`memory/YYYY-MM-DD.md`，记录每天的事件
- **长期记忆**：`MEMORY.md`，存储精选的经验教训
- **Active Memory**：新会话前自动注入相关记忆

## 配置优化

我们使用 `nvidia/nv-embed-v1` 远程 embedding 模型，提供高精度检索。

## 常见问题

**Q: 为什么早上会话会失忆？**  
A: 这是因为 Active Memory 未启用。启用后新会话会自动注入记忆。

**Q: 如何验证记忆系统工作？**  
A: 在新会话中询问"昨天我们做了什么"，应能自动回忆。
